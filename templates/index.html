// architecture du modèle
Graph Attention Network
Entrée : Flux réseau → Nœuds du graphe (53 features)
Graphe KNN : k=5 voisins les plus proches (similarité cosinus)

GATConv Layer 1 : 53 → 128 dims × 8 têtes = 1024 dims
   BatchNorm1d → ELU → Dropout(0.5)

GATConv Layer 2 : 1024 → 64 dims × 4 têtes = 256 dims
   BatchNorm1d → ELU

Classifieur binaire  : Linear(256 → 2) — Normal / Attaque
Classifieur multi   : Linear(256 → 8) — 8 types d'attaques

Dataset : CIC-IDS 2017 + CIC-IDS 2018 (combiné pour couvrir toutes les classes)
// fonctionnalités
Ce que le système détecte
01 / DDoS & DoS

Déni de Service

Détecte les attaques de saturation réseau, qu'elles soient distribuées (DDoS) ou mono-source (DoS).

02 / BruteForce

Attaques par Force Brute

SSH, HTTP, FTP — tentatives répétées de connexion détectées par l'analyse des patterns de flux.

03 / Botnet

Machines Zombies

Identification des machines compromises et contrôlées à distance par analyse comportementale.

04 / WebAttack

Attaques Web

Injection SQL, XSS, et autres vecteurs d'attaque ciblant les applications web.

05 / PortScan

Reconnaissance

Détecte les scans de ports utilisés pour cartographier les services exposés sur le réseau.

06 / Infiltration

Accès Non Autorisé

Identification des tentatives d'accès illicite au réseau interne via des techniques furtives.
